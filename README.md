# Chewsy Gum Shop

Responsive chewing-gum storefront built with React, TypeScript, Vite, and Tailwind CSS.

## Live Demo

https://chewsy-gum-shop-a4mijn.v2.appdeploy.ai/

## Preview

![Chewsy Gum Shop storefront preview](assets/chewsy-storefront.webp)

## Features

- Flavor filtering and product search
- Shopping bag with quantity controls and subtotal calculation
- Responsive desktop and mobile layouts
- Demo checkout flow with validation
- No real payments or orders are processed

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
